# Frontend Source Code Map

Scope: React application source under `frontend/src/`.

## Responsibilities

- wire routing, auth gating, and error boundaries
- define typed API access and shared frontend types
- compose pages from feature components and shared UI primitives

## Read-next guidance

- Route or auth-redirect behavior -> `App.tsx`
- Backend request contract or cache key issue -> `api.ts`
- A response rejected as `ApiValidationError` / `[api] Response validation failed` -> the schema in `lib/schemas.ts`, `lib/knowledgeSchemas.ts`, `lib/runtimeSchemas.ts` or `lib/opsSchemas.ts`, then `lib/apiValidation.ts` (convention: `docs/docs/tech-spec/frontend.md`, "Validation and Resilience")
- UI composition or page-level behavior -> `pages/` then `components/CODEMAP.md`
- Shared component structure -> `components/CODEMAP.md`
