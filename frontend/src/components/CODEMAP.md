# Frontend Components Code Map

Scope: shared and feature-specific React components under `frontend/src/components/`.

## Responsibilities

- provide reusable UI primitives
- package domain-focused feature components that own their own queries and mutations
- define the dashboard layout shell used by routed pages

## Read-next guidance

- Classic shell layout or navigation change -> `layout/Layout.tsx`, `layout/AppSidebar.tsx`
- Alternate (UIv2) shell change -> `layout-v2/LayoutV2.tsx`
- Alternate (UIv3) shell change -> `layout-v3/LayoutV3.tsx`
- Adding or renaming a shell -> `contexts/uiVersion.ts` (the shell registry), `appShells.ts` (the shell's lazy import), and the anti-flash bootstrap in `public/ui-shell-bootstrap.js`
- Navigation items shown by every shell -> `layout/useNavItems.ts`
- In-page section/tab navigation (Settings, memory page) -> `layout/PageSectionNav.tsx`
- Briefing/chat interaction -> `../contexts/ChatSessionContext.tsx` (socket and session state), `features/BriefingChat.tsx` (the view), `features/ToolCallInspector.tsx` (tool chips), `features/ToolApprovalCard.tsx` (approval card), `features/DelegatedTasksPanel.tsx` with `../lib/delegatedTasks.ts` (the conversation's delegated tasks, JAN-208), and `features/TurnTimeline.tsx` with `../lib/planSteps.ts` (the turn's step timeline, JAN-316), `features/ui-blocks/` and `../lib/uiBlocks.ts` (UI blocks, JAN-252), `../lib/toolCallEvents.ts` (frame parsing), `../lib/pageContext.ts` and `../hooks/pageContextSections.ts` (what page snapshot each message carries, JAN-250), `../lib/uiOutline.ts` and `../lib/uiIntrospection.ts` (what Janus sees when it introspects the page; chat panels carry `data-janus-chat` so it never reads them, JAN-285), `../pages/ChatPage.tsx` (`/chat`), and `features/BriefingWidget.tsx` (dashboard/briefing-page panel)
- Where each shell mounts the chat -> the shell file plus `../hooks/useMediaQuery.ts`; the shared placement contract is `../test/shellChatPlacement.tsx`
- Agent memory management -> `features/MemoryManager.tsx`
- Email list behavior -> `features/EmailList.tsx` and `features/EmailItem.tsx`
- Email detail, priority actions, or clarification review -> `features/EmailDetailView.tsx`, `features/EmailPriorityActions.tsx`, `features/EmailClarificationQueue.tsx`
- Topic tracking UI -> `features/TopicManager.tsx`
- Document uploads and ingested knowledge sources -> `features/KnowledgeSourcesManager.tsx`
- Knowledge extraction, entities, and merge review -> `features/KnowledgeGraphManager.tsx`
- Wiki pages, edits, and proposals -> `features/WikiManager.tsx`, `features/WikiPageView.tsx`; page sources and the knowledge graph -> `features/WikiProvenance.tsx`, `features/KnowledgeGraphView.tsx`, `../lib/knowledgeStack.ts`; `[[Page]]` wiki links -> `../lib/wikiLinks.ts`, `features/JanusMarkdown.tsx`, `features/wikiLinkTarget.ts`
- Knowledge search and entity detail -> `features/KnowledgeSearchPanel.tsx`, `features/KnowledgeEntityDetail.tsx`
- Settings surface for accounts or LLMs -> the matching file in `features/`
- Integration settings (GitHub, Google/Microsoft connections, Linear, web search, MCP, mail ingestion) -> the matching `features/*Config.tsx` / `MCPRegistryManager.tsx` file
- WhatsApp account/pairing behavior -> `features/WhatsAppAccountManager.tsx`
- Memory/knowledge surface for rules and durable facts -> `features/RuleManager.tsx` and `features/MemoryManager.tsx`
- Runtime trigger presentation (status colours, lifecycle steps, widget styles) -> `features/triggers/`
- Shared styling or primitive behavior -> matching file in `ui/`
