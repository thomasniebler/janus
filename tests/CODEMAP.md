# Tests Code Map

Scope: backend and integration-focused tests under `tests/`.

## Responsibilities

- protect authentication, email processing, planner/reminder, status, and migration behavior
- provide regression coverage for schema upgrades and security-sensitive paths

## Read-next guidance

- Any bug fix touching existing behavior -> open the matching test file first
- Chat-agent delegation or conversation tracking -> `test_delegation.py`, `test_delegation_wait.py`, `test_conversation_delegations.py`, `test_conversations.py`, and `test_agent_tools.py`
- Migration/startup issue -> `test_database_migrations.py` (and `test_postgres_migrations.py` for PostgreSQL-specific behavior)
- CLI, app startup, worker registration, or legacy `janus.main` compatibility -> `test_main.py`
- Live UI refresh / `/ws/changes` -> `test_domain_changes.py`
